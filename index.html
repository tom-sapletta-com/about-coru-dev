Koru — the open-source, fully autonomous refactor loop.
It finds the debt, plans the work, drives an AI to fix it, verifies everything, and repeats. While you sleep.

Detect→ Plan→ Execute→ Verify→ Heal→ Repeat

The problem

Tech debt grows faster than you can pay it down

Complexity creeps in with every sprint. Quality gates report the damage — but reports don't refactor code. AI editors can fix things — but somebody has to feed them tickets, check the results, and keep them honest, file after file, repo after repo.

📈

Findings pile up

Linters and gates produce lists. Lists become backlog noise nobody owns.

🖱️

AI needs a driver

Copy the prompt, paste the diff, run the tests, again and again. That's a loop — a machine's job.

🎲

No verification, no trust

Unverified AI edits are a regression lottery. Teams turn automation off after the first incident.

The answer

A closed loop with a ticket queue at its heart

Every finding becomes a scoped, deduplicated planfile ticket. The autonomous cycle takes the next ticket, drives an executor, verifies with tests + quality gates (regix), records every step in an event log, and only then commits. Red gates create new tickets — the loop feeds itself.

Headless LLM

Tickets go straight to a model API — OpenRouter or any local OpenAI-compatible endpoint — with per-run cost tracking.

MiniMaxQwen3-coderDeepSeeklocal llama

One queue, one verification pipeline — the execution lane is just a setting. If a lane is unavailable, Koru rescues the drive through another one.

Trust, engineered

Autonomy you can audit

🎫

Ticket-scoped changes

Every edit traces back to a ticket with inputs, outputs, and history. Resumable after any interruption.

🛡️

Gates before commit

Tests, complexity and maintainability thresholds (regix), behavioral probes (TestQL) — red means no commit.

🩹

Self-healing lanes

CLI missing? Editor busy? The drive falls back across lanes (GUI driver, OS input) instead of stalling.

📊

Event-sourced history

JSONL event store + live dashboard. You can replay exactly what the loop did and why.
